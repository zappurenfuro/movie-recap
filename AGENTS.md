# Installing or updating this skill

Read README.md and references/setup.md before setup. A request to install this repository starts onboarding, not rendering. Show the dependency/model list, destinations, network and disk requirements, then obtain installation permission before running the installer or installing missing prerequisites. Separately ask about automatic YouTube publishing. Never treat installation permission as upload permission.

Use references/publishing.md for optional browser sign-in and private channel confirmation. Never ask for passwords, cookies or tokens in chat. Keep account names, channel IDs, personal paths, preferences, source films, outputs and credentials outside this repository. Existing private settings must not become public defaults.

For updates, preserve local authorization and user modifications. Test installer changes with `python -m unittest discover -s tests -v`. Release archives must contain reviewed tracked files only, never a recursive copy of an installed skill or home directory.
